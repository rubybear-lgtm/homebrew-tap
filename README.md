# Homebrew tap for pinchpass

Cask for [pinchpass](https://github.com/rubybear-lgtm/PinchPass) — one-time
E2E-encrypted secret request links.

```sh
brew install --cask rubybear-lgtm/tap/pinchpass
brew upgrade --cask pinchpass
```

`Casks/pinchpass.rb` is generated and committed by GoReleaser from the PinchPass
release workflow. Do not edit it by hand — it is overwritten on the next release.
